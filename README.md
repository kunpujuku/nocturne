# 薫風塾・星月夜の暦（NOCTURNE）

ブラウザで動作する、薫風塾の小さな暦アプリです。

## 公開方法（GitHub Pages）
1. GitHubで新しい公開リポジトリを作成（例：`nocturne`）。
2. `index.html` をリポジトリ直下にアップロード。
3. Repository の **Settings → Pages** を開く。
4. **Deploy from a branch** を選び、`main` / `/ (root)` を指定して Save。
5. 数分後、表示された GitHub Pages のURLで公開を確認。

## 機能
- 観測地点を選べる月齢・月相・月の出入り表示
- 日替わりの大アルカナ風メッセージ
- 2027年1月16日の共通テストまでの残日数
- 日替わりの言葉
- 日替わり一問チャレンジ
- 二十四節気の目安
- 七十二候（平年の日付に基づく簡易表示）と季節別の万葉集四首
- 四季で色調が変わるタロットカード背景
- クリスマス・元日・初星・節分の季節限定カード
- 英語・数学・国語・日本史・世界史の問題データを拡充

## 技術上の注意
- 月齢は新月基準時刻と朔望月から求める概算値です。
- 月の出・入りは SunCalc（jsDelivr CDN）を利用します。インターネット接続が必要です。
- 観測地点は都市の代表座標です。宮口は浜松市浜名区周辺の概略座標です。
- 二十四節気・七十二候の日付は簡易的な目安で、年ごとの厳密な暦計算ではありません。七十二候は日付を5日程度で区切る近似表示です。
- 万葉集は春・夏・秋・冬の代表歌を各1首掲載。本文・歌番号・作者・現代語訳を確認し、奈良県立万葉文化館の歌詳細へリンクしています。季節との対応はアプリ独自の編集上の選択です。
- 季節限定カードは現在、クリスマス（12/24・25）、新年（1/1・2）、節分（2/3）を実装しています。
- 共通テスト日は2027年1月16日を設定しています。年度更新時には `index.html` の日付を変更してください。
- 占い・引用風の短文はアプリ用のオリジナル文言を中心にしています。娯楽・学習のきっかけとしてご利用ください。
